# Christmas Countdown

A responsive, dependency-free countdown to **24 December 2026 at 12:10 Europe/Vienna time**.

## Run locally

Open `public/index.html` in a browser, or serve the `public` directory with any static file server.

## Hosting

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the `public` directory to GitHub Pages whenever changes are pushed to `main`. The public site URL is:

https://bidzag98.github.io/christmas-countdown/
