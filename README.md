# Christmas Countdown

A responsive, dependency-free countdown to **24 December 2026 at 12:10 Europe/Vienna time**.

## Run locally

Open `public/index.html` in a browser, or serve the `public` directory with any static file server.

## Share the countdown

Share this link to open the countdown on phones and computers:

https://htmlpreview.github.io/?https://github.com/BIDZAG98/christmas-countdown/blob/main/public/index.html

The link uses GitHub HTML Preview to serve this public repository's page without enabling GitHub Pages. For a permanent, branded hosting URL, GitHub Pages needs to be enabled once in the repository settings.
